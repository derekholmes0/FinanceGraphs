# Add single date signals to time series graphs.

Event Helpers: fg_signal_to_events

## Usage

``` r
fg_signal_to_events(signal_df, colormap)
```

## Arguments

- signal_df:

  A two-column `data.frame` with first being a date and second being any
  (factor-like) signal parameter.

- colormap:

  A two column `data.frame` with the first being the possible signal
  (see Example) and the second a color. description

## Value

`data.table` suitable for passing into
[`fgts_dygraph()`](https://derekholmes0.github.io/FinanceGraphs/reference/fgts_dygraph.md)
via the `event_ds` parameter

## Details

This helper applies run-length encoding to match the signal in
`signal_df` to the color in `colormap`
